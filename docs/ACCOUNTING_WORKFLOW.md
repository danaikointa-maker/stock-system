## 👑 1. เจ้าของระบบ (HQ / SystemAdmin)

### บทบาท
- **ผู้บริหารสูงสุด** — เห็นภาพรวมทุกเอกสาร ทุกสาขา
- **ผู้อนุมัติ** — อนุมัติใบสั่งซื้อใหญ่, อนุมัติใบเบิก
- **ผู้ตรวจสอบ** — Audit, ตรวจสอบยอดตรง, ดูงบการเงิน

### เอกสารที่ใช้ได้ (ทั้งหมด)

| เอกสาร | สิทธิ์ | หน้าที่ |
|--------|-------|---------|
| 📊 Dashboard บัญชี | ✅ ดู | ภาพรวม KPI ทุกสาขา |
| 📋 ใบเสนอราคา | ✅ ดูทั้งหมด | ติดตามยอดขายจากทุกสาขา |
| 📄 บิลเรียกเก็บ | ✅ ดู + สร้าง + ยกเลิก | จัดการลูกหนี้ทุกสาขา |
| 💰 บิลรับ | ✅ ดู + สร้าง | ติดตามรายได้ทุกสาขา |
| 🚚 ใบส่งของ | ✅ ดู + สร้าง | ติดตามการส่งของทุกสาขา |
| 🛒 ใบสั่งซื้อ | ✅ ดู + สร้าง + อนุมัติ | จัดการเจ้าหนี้, อนุมัติ PO |
| 💸 บิลจ่าย | ✅ ดู + สร้าง | จัดการค่าใช้จ่ายทุกสาขา |
| 🧾 ใบกำกับภาษี | ✅ ดู + สร้าง | จัดการ VAT ทุกสาขา |
| 📋 หัก ณ ที่จ่าย | ✅ ดู | ติดตาม WHT ที่ต้องนำส่ง |
| ↩️ ใบลดหนี้ | ✅ ดู + สร้าง | จัดการคืนสินค้า/ส่วนลด |
| 📒 ลงบัญชีแยก | ✅ ดู + สร้าง + โพสต์ | ปรับปรุงบัญชี |
| 📋 Stock Ledger | ✅ ดู | ตรวจสอบ movement ทั้งหมด |
| 🔍 Audit | ✅ ใช้ | ตรวจสอบยอดตรง |
| 🗂️ ผังบัญชี | ✅ ดู | ดูโครงสร้างบัญชี |

### งบการเงินที่ใช้

| งบ | ใช้ทำอะไร |
|----|----------|
| 📈 งบกำไรขาดทุน | ดูรายได้ - ค่าใช้จ่าย = กำไร/ขาดทุน |
| 🏦 งบแสดงฐานะ | ดูสินทรัพย์ = หนี้สิน + ทุน |
| ⚖️ งบทดลอง | ตรวจสอบ Dr = Cr สมดุล |
| 📒 General Ledger | ดูรายการแยกตามบัญชี |
| ⏳ AR/AP Aging | ดูอายุหนี้ลูกหนี้/เจ้าหนี้ |

### ขั้นตอนการทำงาน

```
1. เปิด Dashboard → ดู KPI: ยอดขาย, ยอดรับ, ยอดจ่าย, กำไร, หนี้คงค้าง
2. ตรวจสอบ Audit → Stock Ledger ตรงกับ StockBalance? Journal Dr=Cr?
3. ดู AR/AP Aging → ลูกหนี้ค้างนาน? เจ้าหนี้ถึงกำหนดจ่าย?
4. อนุมัติ PO → ตัวแทน/ร้านค้าสร้าง PO → เจ้าของอนุมัติ → สั่งซื้อ
5. ดูงบกำไรขาดทุน → วิเคราะห์รายได้/ค่าใช้จ่าย/กำไร
6. ดูงบแสดงฐานะ → วิเคราะห์สุขภาพการเงิน
```

### การเชื่อมโยงเอกสาร

```
ทุกเอกสารจากทุกสาขา → ไหลขึ้นหาเจ้าของระบบอัตโนมัติ
  ├── ใบเสนอราคา (QT) → เจ้าของเห็นทันที
  ├── บิลเรียกเก็บ (INV) → เจ้าของเห็น + ติดตามหนี้
  ├── ใบส่งของ (DLV) → เจ้าของเห็น + ตรวจสอบสต๊อก
  ├── ใบเสร็จ (RCP) → เจ้าของเห็น + ตรวจสอบรายได้
  ├── บิลจ่าย (PAY) → เจ้าของเห็น + ตรวจสอบค่าใช้จ่าย
  ├── ใบสั่งซื้อ (PO) → ต้องอนุมัติก่อนสั่งซื้อ
  └── Journal Entries → เจ้าของตรวจสอบความถูกต้อง
```

## 👔 2. ตัวแทนขาย (Agent)

### บทบาท
- **ฝ่ายขาย** — หาลูกค้า, ออกใบเสนอราคา, ปิดการขาย
- **ฝ่ายจัดส่ง** — จัดการใบส่งของ, ติดตามการขนส่ง
- **ฝ่ายติดตามหนี้** — ติดตามการชำระเงินจากลูกค้า

### เอกสารที่ใช้ได้

| เอกสาร | สิทธิ์ | หน้าที่ |
|--------|-------|---------|
| 📋 ใบเสนอราคา | ✅ สร้าง + ดู + ส่ง + รับ | เสนอราคาลูกค้า, ติดตามสถานะ |
| 📄 บิลเรียกเก็บ | ✅ สร้าง + ดู | ออกบิลให้ลูกค้าหลังตกลง |
| 🚚 ใบส่งของ | ✅ สร้าง + ดู + ส่ง | จัดการส่งของ, ติดตามขนส่ง |
| ↩️ ใบลดหนี้ | ✅ สร้าง + ดู | จัดการคืนสินค้า/ส่วนลด |
| 💰 บิลรับ | ✅ สร้าง + ดู | รับเงินจากลูกค้า |
| 🧾 ใบกำกับภาษี | ✅ สร้าง + ดู | ออกใบกำกับภาษีให้ลูกค้า |
| 📈 รายงาน | ✅ ดู | ดูยอดขาย/ลูกหนี้ ของตน |

### ขั้นตอนการทำงาน (Workflow)

```
┌─────────────────────────────────────────────────────────────────┐
│  ขั้นตอน 1: เสนอราคา                                              │
│  📋 สร้างใบเสนอราคา (QT) → ส่งให้ลูกค้า → ลูกค้าพิจารณา            │
│  ─────────────────────────────────────────────────────────────── │
│  ผล: ลูกค้าได้รับใบเสนอราคา → ตอบตกลง หรือ ปฏิเสธ                   │
└──────────────────────────┬──────────────────────────────────────┘
                           │ ลูกค้าตกลง
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  ขั้นตอน 2: ออกบิลเรียกเก็บ                                        │
│  📄 แปลง QT → บิลเรียกเก็บ (INV)                                   │
│  ─────────────────────────────────────────────────────────────── │
│  ผล: สร้างเอกสาร INV → บันทึกบัญชี:                                │
│    Dr. ลูกหนี้การค้า (A/R)                                         │
│    Cr. รายได้จากการขาย                                             │
│    Cr. VAT ต้องนำส่ง                                               │
│  ─────────────────────────────────────────────────────────────── │
│  📊 เจ้าของระบบเห็นทันที: ลูกหนี้เพิ่มขึ้น, รายได้เพิ่มขึ้น           │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  ขั้นตอน 3: ส่งของ                                                │
│  🚚 สร้างใบส่งของ (DLV) → กด "ส่งของ"                               │
│  ─────────────────────────────────────────────────────────────── │
│  ผล: ตัดสต๊อกอัตโนมัติ + บันทึกบัญชี:                               │
│    Dr. ต้นทุนขาย (COGS)                                           │
│    Cr. สินค้าคงเหลือ (Inventory)                                   │
│  ─────────────────────────────────────────────────────────────── │
│  📦 Stock Ledger: บันทึก movement (immutable)                      │
│  📊 เจ้าของระบบเห็นทันที: สตอกลดลง, COGS เพิ่มขึ้น                   │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  ขั้นตอน 4: รับเงิน                                                │
│  💰 ลูกค้าชำระ → สร้างใบเสร็จ (RCP) เชื่อมกับ INV                    │
│  ─────────────────────────────────────────────────────────────── │
│  ผล: อัพเดท INV balance อัตโนมัติ + บันทึกบัญชี:                    │
│    Dr. เงินสด/ธนาคาร                                               │
│    Cr. ลูกหนี้การค้า (A/R)                                         │
│  ─────────────────────────────────────────────────────────────── │
│  📊 เจ้าของระบบเห็นทันที: เงินสดเพิ่มขึ้น, ลูกหนี้ลดลง                │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  ขั้นตอน 5: ออกใบกำกับภาษี (ถ้านิติบุคคล)                            │
│  🧾 สร้างใบกำกับภาษี (TXI) เชื่อมกับ INV                            │
│  ─────────────────────────────────────────────────────────────── │
│  ผล: เอกสาร TXI สำหรับยื่น VAT ภ.พ.30                              │
│  📊 เจ้าของระบบเห็น: VAT ที่ต้องนำส่ง                                │
└─────────────────────────────────────────────────────────────────┘
```

### กรณีคืนสินค้า/ส่วนลด

```
┌─────────────────────────────────────────────────────────────────┐
│  ↩️ สร้างใบลดหนี้ (CN) → ระบุเหตุผล → ยืนยัน                        │
│  ─────────────────────────────────────────────────────────────── │
│  ผล (กรณีคืนสินค้า):                                               │
│    Dr. สินค้าคงเหลือ (เพิ่มกลับ)                                    │
│    Cr. ต้นทุนขาย (กลับรายการ)                                       │
│    Dr. รายได้ (ลด)                                                  │
│    Dr. VAT (ลด)                                                    │
│    Cr. ลูกหนี้ (ลด)                                                 │
│  ─────────────────────────────────────────────────────────────── │
│  📦 Stock Ledger: บันทึก return_in (immutable)                     │
│  📊 เจ้าของระบบเห็นทันที: สต๊อกเพิ่มกลับ, รายได้ลด                    │
└─────────────────────────────────────────────────────────────────┘
```

### การเชื่อมโยงกับเจ้าของระบบ

```
ตัวแทนทำ:                เจ้าของเห็น:
├── สร้าง QT ──────→ เห็นใบเสนอราคาทั้งหมด
├── แปลงเป็น INV ──→ เห็นบิลเรียกเก็บ + ลูกหนี้เพิ่ม
├── ส่งของ (DLV) ──→ เห็นสตอกลด + COGS เพิ่ม
├── รับเงิน (RCP) ──→ เห็นเงินเข้า + ลูกหนี้ลด
├── ออก TXI ───────→ เห็น VAT ที่ต้องนำส่ง
└── สร้าง CN ──────→ เห็นสต๊อกเพิ่ม + รายได้ลด
```

## 🏪 3. ร้านค้า (Shop)

### บทบาท
- **หน้าร้าน** — ขายสินค้าผ่าน POS, รับเงินจากลูกค้า
- **รับของ** — รับของจากตัวแทน, ตรวจสอบความถูกต้อง
- **แลกแต้ม** — รับแลกแต้มจากลูกค้า

### เอกสารที่ใช้ได้

| เอกสาร | สิทธิ์ | หน้าที่ |
|--------|-------|---------|
| 🛒 POS (ขาย) | ✅ สร้าง | เปิดบิลขายหน้าร้าน |
| 💰 บิลรับ | ✅ ดู | ดูประวัติรับเงิน |
| 📦 สต๊อก | ✅ ดู | ดูสต๊อกคงเหลือของตน |
| 🎁 แลกแต้ม | ✅ ดู + รับแลก | รับแลกของรางวัล |

### ขั้นตอนการทำงาน

```
┌─────────────────────────────────────────────────────────────────┐
│  ขั้นตอน 1: เปิดบิลขาย POS                                        │
│  🛒 เลือกสินค้า → ระบุลูกค้า → ชำระเงิน                               │
│  ─────────────────────────────────────────────────────────────── │
│  ผล: ตัดสต๊อก + สะสมแต้ม + บันทึกบัญชีอัตโนมัติ:                      │
│    Dr. เงินสด/ธนาคาร                                               │
│    Cr. รายได้จากการขาย                                             │
│    Dr. ต้นทุนขาย (COGS)                                           │
│    Cr. สินค้าคงเหลือ                                               │
│  ─────────────────────────────────────────────────────────────── │
│  📊 เจ้าของเห็นทันที: ยอดขาย, สตอกลด, เงินสดเพิ่ม                    │
└─────────────────────────────────────────────────────────────────┘
```

## 🏭 5. คลังใหญ่ (Warehouse)

### บทบาท
- **รับของเข้า** — รับสินค้าจากผู้ผลิต/ผู้ขาย
- **กระจายสินค้า** — โอนสินค้าไปคลังย่อย/ตัวแทน
- **จัดการสต๊อก** — นับสต๊อก, ปรับยอด

### เอกสารที่ใช้ได้

| เอกสาร | สิทธิ์ | หน้าที่ |
|--------|-------|---------|
| 🛒 ใบสั่งซื้อ (PO) | ✅ สร้าง + ดู | สั่งซื้อสินค้าจากผู้ขาย |
| 💸 บิลจ่าย | ✅ สร้าง + ดู | จ่ายเงินค่าสินค้า |
| 📋 WHT | ✅ ดู | ดู WHT ที่หักไว้ |
| 🚚 ใบส่งของ | ✅ สร้าง + ดู | ส่งของไปคลังย่อย/ตัวแทน |
| 📦 สต๊อก | ✅ ดู + จัดการ | ดูสต๊อก, นับ, ปรับ |

### ขั้นตอนการทำงาน

```
┌─────────────────────────────────────────────────────────────────┐
│  ขั้นตอน 1: สั่งซื้อ                                               │
│  🛒 สร้าง PO → อนุมัติ → ส่งให้ผู้ขาย                               │
│  ─────────────────────────────────────────────────────────────── │
│  ผล: บันทึกบัญชีเมื่ออนุมัติ:                                        │
│    (ยังไม่บันทึก — บันทึกตอนรับของ)                                  │
└──────────────────────────┬──────────────────────────────────────┘
                           │ รับของ
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  ขั้นตอน 2: รับของเข้า                                             │
│  📥 รับของ → เพิ่มสต๊อก → บันทึกบัญชี:                                │
│    Dr. สินค้าคงเหลือ (Inventory)                                   │
│    Cr. เจ้าหนี้การค้า (A/P)                                        │
│  ─────────────────────────────────────────────────────────────── │
│  📦 Stock Ledger: บันทึก receipt (immutable)                       │
│  📊 เจ้าของเห็นทันที: สต๊อกเพิ่ม, เจ้าหนี้เพิ่ม                       │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  ขั้นตอน 3: จ่ายเงิน                                               │
│  💸 สร้างบิลจ่าย (PAY) + WHT → จ่ายเงิน                              │
│  ─────────────────────────────────────────────────────────────── │
│  ผล: บันทึกบัญชี:                                                  │
│    Dr. เจ้าหนี้การค้า (A/P)                                        │
│    Cr. เงินสด/ธนาคาร                                               │
│    (WHT หักจากยอดก่อน VAT)                                        │
│  ─────────────────────────────────────────────────────────────── │
│  📊 เจ้าของเห็นทันที: เจ้าหนี้ลด, เงินสดลด, WHT ที่ต้องนำส่ง           │
└─────────────────────────────────────────────────────────────────┘
```

## 📊 ผลกระทบทางบัญชีของแต่ละเอกสาร

| เอกสาร | Debit (Dr.) | Credit (Cr.) | กระทบ |
|--------|-------------|---------------|-------|
| **INV** (บิลเรียกเก็บ) | ลูกหนี้ (A/R) | รายได้ + VAT | ลูกหนี้เพิ่ม, รายได้เพิ่ม |
| **DLV** (ใบส่งของ) | ต้นทุนขาย (COGS) | สินค้าคงเหลือ | สตอกลด, COGS เพิ่ม |
| **RCP** (ใบเสร็จ) | เงินสด/ธนาคาร | ลูกหนี้ (A/R) | เงินสดเพิ่ม, ลูกหนี้ลด |
| **TXI** (ใบกำกับภาษี) | — (อ้างอิง INV) | — | VAT ที่ต้องนำส่ง |
| **PO** (ใบสั่งซื้อ) | — (ยังไม่บันทึก) | — | บันทึกตอนรับของ |
| **รับของ** | สินค้าคงเหลือ | เจ้าหนี้ (A/P) | สต๊อกเพิ่ม, เจ้าหนี้เพิ่ม |
| **PAY** (บิลจ่าย) | เจ้าหนี้ (A/P) | เงินสด/ธนาคาร | เจ้าหนี้ลด, เงินสดลด |
| **WHT** (หัก ณ ที่จ่าย) | — (อ้างอิง PAY) | — | WHT ที่ต้องนำส่ง |
| **CN** (ใบลดหนี้) | สินค้าคงเหลือ + รายได้ลด | COGS ลด + ลูกหนี้ลด | สต๊อกเพิ่ม, รายได้ลด |
| **JV** (ลงบัญชีแยก) | บัญชีที่กำหนด | บัญชีที่กำหนด | ปรับปรุงบัญชี |

## 🔢 สูตรคำนวณที่ถูกต้อง

### บิลเรียกเก็บ / ใบเสนอราคา (ขาย)
```
subtotal    = Σ (qty × unit_price)          ← ราคาก่อน VAT
vat_amount  = subtotal × vat_rate / 100
total       = subtotal + vat_amount
paid_amount = Σ receipts
balance     = total - paid_amount           ← คงค้าง (ไม่หัก CN)
```

### บิลจ่าย + หัก ณ ที่จ่าย (ซื้อ)
```
income_amount = ยอดก่อน VAT (user กรอก)
vat_amount    = income_amount × vat_rate / 100
amount        = income_amount + vat_amount  ← ยอดรวม
wht_amount    = income_amount × wht_rate / 100  ← WHT จากยอดก่อน VAT!
net_amount    = amount - wht_amount         ← จ่ายสุทธิ
```

### ตัวอย่างคำนวณ
```
ค่าบริการ 10,000 บาท + VAT 7% - WHT 3%

income  = 10,000
VAT     = 700
amount  = 10,700
WHT     = 300  (10,000 × 3% ไม่ใช่ 10,700 × 3%)
net     = 10,400
```

## 🔄 ตัวอย่างสถานการณ์จริง

### สถานการณ์: ตัวแทนขาย ปิดการขาย 3,000 บาท

```
1. ตัวแทนสร้าง QT → ส่งให้ลูกค้า
   📋 QT2609-0001: น้ำดื่ม 200 ขวด × 15 = 3,000 + VAT 210 = 3,210

2. ลูกค้าตกลง → ตัวแทนแปลง QT เป็น INV
   📄 INV2609-0001: 3,210 บาท (คงค้าง 3,210)
   📊 เจ้าของเห็น: ลูกหนี้ +3,210, รายได้ +3,000

3. ตัวแทนสร้าง DLV → กดส่งของ
   🚚 DLV2609-0001: 200 ขวด
   📦 Stock Ledger: ส่งออก 200 ชิ้น (immutable)
   📊 เจ้าของเห็น: สต๊อก -200, COGS +1,600

4. ลูกค้าชำระ 2,000 บาท → ตัวแทนสร้าง RCP
   💰 RCP2609-0001: 2,000 บาท
   📄 INV คงค้าง: 3,210 - 2,000 = 1,210
   📊 เจ้าของเห็น: เงินสด +2,000, ลูกหนี้ -2,000

5. ลูกค้าคืนสินค้า 20 ขวด (ชำรุด) → ตัวแทนสร้าง CN
   ↩️ CN2609-0001: 300 + VAT 21 = 321 บาท
   📦 Stock Ledger: รับคืน 20 ชิ้น (immutable)
   📊 เจ้าของเห็น: สต๊อก +20, รายได้ -300

6. ลูกค้าชำระที่เหลือ 1,210 บาท → ตัวแทนสร้าง RCP
   💰 RCP2609-0002: 1,210 บาท
   📄 INV คงค้าง: 0 (ชำระครบ)
   📊 เจ้าของเห็น: เงินสด +1,210, ลูกหนี้ -1,210

สรุปผลลัพธ์:
  รายได้สุทธิ: 3,000 - 300 = 2,700
  COGS สุทธิ: 1,600 - 160 = 1,440
  กำไรขั้นต้น: 2,700 - 1,440 = 1,260
  เงินสดรับรวม: 3,210
  สต๊อกสุทธิ: ออก 180 ชิ้น
```
